description: "owner rule: memorise only what shortens troubleshooting time-to-discover; no decisions, directions or menial choices"
metadata:
  type: feedback
---

Save a memory only when it shortens the time to discover the cause of a problem: a failure signature, its cause and its fix. Do not save owner decisions, directions, queued work or status.

**Why:** menial choices pollute memory and mislead later sessions.

**How to apply:** decisions and queued prompts go in the dispatch ledger, which is cleared as work lands. Before writing a memory, ask whether it would have made a past fault faster to find.
